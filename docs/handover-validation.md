日期：2026-11-24。目的为验证交接包能脱离发送者 Git 历史、原 data/ 和原虚拟环境运行，不以主环境已经运行代替新环境复现。

## 环境和步骤

- 在 `data/handover-verification/venv` 新建 Python 3.11.4 虚拟环境，`include-system-site-packages=false`。
- 仅安装 `requirements-tested.txt` 列出的 13 个运行依赖，不依赖发送者系统级科学计算/PDF 工具。
- 以 `scripts/make_handover.py` 打包当前工作区，解压候选包至全新目录；首次解压不含 `.git`、`data`、账号或 SQLite。
- 在解压目录运行文件清单校验、无 Git 的团队边界校验、全量 Python 回归和数据库外部兼容脚本。
- 在解压目录初始化新账号，实际启动网页 8044、节点 8244/8245 和独立工作进程；通过真实 HTTP 登录、上传、发布、查询、导出及权限检查。
