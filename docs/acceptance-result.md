完整版本当前运行在 http://127.0.0.1:8002/ ，两个批次节点使用 8200、8201。原先的 8000 进程未被停止，打开完整版本时请使用 8002。

使用本机 `data/local-accounts.json` 中的 `admin` 或 `viewer` 登录；该文件已被忽略，不进入仓库。完整服务的启动与管理命令见 [完整开发与验收手册](full-system.md) 和根目录 README。
