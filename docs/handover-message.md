# 可直接转发给系统开发同学的文字

这是截至 2026-11-24 的 PositionDataManage 完整系统交接版。GitHub 请取 `feature/checkin-query` 分支，也可用重新生成并逐项校验的交接 ZIP；不要只下载 `main` 起步版。

解压后先看 `docs/handover.md`，按其中步骤安装 `requirements-tested.txt`、初始化账号并启动服务；测试步骤在 `docs/testing-handover.md`，课程要求对照在 `docs/course-compliance.md`，报告素材在 `docs/report-guide.md`，正式汇报脚本在 `docs/defense-five-minutes.md`。

新电脑只有首次需要创建虚拟环境、安装依赖、初始化本机账号。完成后，每次都只运行 `.\.venv\Scripts\python.exe scripts/run_local.py --port 8002 --node-port 8200`，与发送者本机一样；校验和测试脚本不是每日启动步骤。

已经实现原始数据导入、真实清洗接入、双节点分片/批次发布、时空查询、真实城市地图与列表联动、分类目录、后台完整 CSV/GeoJSON 导出、登录权限和历史回退。交接包在不含原 Git/data 的干净环境复验了 76 项 Python 测试（73 正常通过、3 个清洗已知预期失败）、11 项数据库兼容测试及样例 HTTP 全流程。

包里没有真实原始数据、SQLite、密码和虚拟环境，需要你本机初始化。先用 sample/ 构造样例联调；老师原数据需要时我们通过课程授权渠道另行共享。本机全量实际 6442892 行，当前发布 6430640 条、节点 3225556/3205084，详细证据摘要在 docs/evidence/。

接手优先做新电脑复现、最终页面/网络/权限回归、统一截图与结果表、报告和五分钟 PPT；清洗众数及计数缺陷由清洗同学修复，数据库实现和索引由数据库同学维护，不要直接改 cleaning/、db/ 和团队 compose.yaml。课程要求报告不少于 3000 字，PPT 不超过 5 分钟；原附件截止 12 月 2 日 17:00，汇报暂定 12 月 3 日 18:00，以后续通知为准。

这个 ZIP 是工作区源码快照，不带 Git 历史。如果你已经有后续模块更新，请在自己的分支核对差异合并，不要整包无条件覆盖已有新工作。原始附件和逐项完成状态也在包内。收到后请记录本机复验问题，按模块归属一起联调。
